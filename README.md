# NIGHTOWL STUDIO — Editorial Graphic Design Portfolio

A premium, animation-led portfolio website for **NIGHTOWL STUDIO**, specializing in commercial advertising posters, large-format outdoor flex banners, high-stopping-power social media campaigns, and event branding.

## Creative Direction & Identity

- **Visual Theme**: Deep obsidian / ink / cobalt color world with tactile paper nano-grain texture.
- **Typography**: Minimal, sleek, and elegant pairing of **Inter**, **Plus Jakarta Sans**, and **Space Mono**.
- **Artwork Archive**: Features 17 commercial campaigns and posters across automotive (Porsche, Ford Mustang, Jawa), luxury accessories (Gucci, Titan, Embark), technology (iPhone 16 Pro Max), athletic streetwear (Nike Air Jordan), and culinary / food graphics (Chicken Burger, Pizza, Noodles, Cold Coffee).
- **Motion System**: Performant CSS mask wipes, line-draw dividers, interactive case study overlays (`ProjectDetailModal`), and full accessibility with `prefers-reduced-motion`.

## Technology Stack

- **Framework**: Vite + React 19 (TypeScript)
- **Styling**: Pure Vanilla CSS with custom tokens & modular component stylesheets
- **Icons**: Lucide React
- **Performance**: Zero bulky dependencies, 100% responsive across mobile, tablet, and ultra-wide screens

## Getting Started

```bash
# Install dependencies
npm install

# Run local development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
